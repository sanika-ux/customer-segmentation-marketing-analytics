# Customer Segmentation & Marketing Analytics Dashboard

## Overview

This project analyzes customer demographics, spending behavior, and purchasing patterns to identify high-value customer segments and support marketing decision-making.

## Tools Used

* Excel
* Power BI

## Business Questions

* Who are the highest-value customers?
* Which customer groups spend the most?
* How does spending vary across education levels and marital status groups?
* Which product categories generate the highest spending?
* How are customers distributed across value segments?

## Dashboard Features

* Customer Segment Distribution
* Customer Spending by Education Level
* Customer Spending by Marital Status
* Product Category Spending Analysis
* Interactive Filters

## Key Insights

* PhD customers showed the highest average spending.
* Low Value customers formed the largest customer segment.
* Wine products generated the highest spending.
* Customer spending varied across marital status groups.
